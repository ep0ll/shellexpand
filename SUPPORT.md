# Support

For usage questions and design discussions, open a GitHub Discussion or issue
in this repository. Before filing, review the README, architecture guide, and
implementation notes.

For reproducible defects, include:
- the shellexpand version and Go version;
- the smallest input and environment that reproduces the result;
- the expected output and actual output;
- whether built-in Bash syntax or a custom Syntax/Expander is involved.

Do not disclose security-sensitive details in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
